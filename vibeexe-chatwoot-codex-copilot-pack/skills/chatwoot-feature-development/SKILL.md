# Develop a Chatwoot Feature Safely


## Use when

Use this skill for a focused backend, frontend, or full-stack feature.

## Procedure

1. Restate the requested behavior and acceptance criteria.
2. Find and follow the nearest existing Chatwoot pattern.
3. Design the smallest complete change.
4. Preserve authorization and account scoping.
5. Reuse services, policies, serializers, jobs, stores, components, and i18n patterns.
6. Implement in coherent steps without unrelated refactoring.
7. Add the smallest meaningful tests, including failure paths and tenant isolation where relevant.
8. Run targeted checks and report only commands actually executed.

## Completion report

List files changed, behavior delivered, tests run, manual verification, known limitations, and upstream upgrade risk.
