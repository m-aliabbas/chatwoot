# Apply VibeExe Branding


## Brand direction

- Product name: VibeExe
- Primary: `#2563EB`
- Secondary: `#3B82F6`
- Dark: `#0F172A`
- Muted text: `#334155`
- Surface: `#F8FAFC`
- White: `#FFFFFF`
- Tone: premium, clean, modern, trustworthy, AI-enabled B2B SaaS

## Procedure

1. Inventory login, onboarding, navigation, metadata, logos, favicons, emails, notifications, help links, manifests, and installation settings.
2. Separate user-facing branding from technical identifiers, package names, database values, APIs, and licenses.
3. Prefer configuration, shared constants, assets, theme tokens, and translations.
4. Avoid blind global replacement of `Chatwoot`.
5. Support light/dark contexts and responsive sizes.
6. Preserve required attribution and open-source notices.
7. Test favicon, app icon, login, dashboard navigation, outgoing emails, and browser metadata.

## Deliverables

Produce a brand-surface inventory, changed files, remaining Chatwoot references with reasons, and upgrade-risk notes.
